# Роутер - Анархист или Настройка OpenWrt, PassWall2 и кастомных VPN-подписок

Данное руководство описывает полный процесс настройки роутера с прошивкой OpenWrt для работы с нестандартными форматами VPN-подписок (на примере сервисов типа GoVPN/easy-api.live, отдающих конфигурации в формате JSON вместо классических Base64-ссылок). Дополнительно рассматривается настройка роутера для работы в роли домашнего файлового сервера (SMB/FTP).

Руководство протестировано на роутере **Cudy TR3000 v1**, но общая логика применима к любым роутерам с поддержкой OpenWrt.

## 1. Сборка прошивки с нужными пакетами

Наиболее удобный способ получить готовую систему — собрать прошивку через официальный [Firmware Selector](https://firmware-selector.openwrt.org/), заранее интегрировав в нее необходимые драйверы и пакеты.

1. Откройте Firmware Selector и введите модель вашего роутера (например, Cudy TR3000).
2. Разверните меню **Customize** (Настроить).
3. В поле **Installed packages** (Установленные пакеты) скопируйте полный список ниже. В нем стандартный `dnsmasq` уже заменен на `dnsmasq-full` (это жесткое требование для работы PassWall2), а также добавлены все необходимые пакеты для USB, SMB и файловых систем:

```text
apk-mbedtls base-files ca-bundle dnsmasq-full dropbear firewall4 fitblk fstools kmod-crypto-hw-safexcel kmod-gpio-button-hotplug kmod-leds-gpio kmod-nft-offload libc libgcc libustream-mbedtls logd mtd netifd nftables odhcp6c odhcpd-ipv6only ppp ppp-mod-pppoe procd-ujail uboot-envtools uci uclient-fetch urandom-seed urngd wpad-basic-mbedtls kmod-usb3 kmod-mt7915e kmod-mt7981-firmware mt7981-wo-firmware luci luci-app-attendedsysupgrade luci-compat ksmbd-server luci-app-ksmbd vsftpd block-mount kmod-usb-storage kmod-fs-vfat kmod-fs-exfat kmod-fs-ext4 kmod-fs-ntfs3 usbutils
```

4. В поле **uci-defaults script** (Скрипт инициализации) рекомендуется вставить код, который при первом запуске не просто включит WiFi, но и **автоматически создаст вашу точку доступа с заданным именем и паролем**. Это критически важно, если у вас нет возможности подключиться к роутеру по кабелю после прошивки:

```bash
#!/bin/sh

# ЗАДАЙТЕ ИМЯ СЕТИ И ПАРОЛЬ (МИНИМУМ 8 СИМВОЛОВ):
SSID="ShutAllRKN"
WIFI_PASS="12345678"

# Включаем все доступные радиомодули (2.4GHz и 5GHz)
for r in 0 1 2; do
  if uci -q get wireless.radio${r} > /dev/null; then
    uci -q set wireless.radio${r}.disabled='0'
    uci -q set wireless.radio${r}.country='RU'
  fi
done

# Присваиваем имя сети и пароль всем стандартным интерфейсам
for i in 0 1 2; do
  if uci -q get wireless.default_radio${i} > /dev/null; then
    uci -q set wireless.default_radio${i}.ssid="$SSID"
    uci -q set wireless.default_radio${i}.encryption='psk2'
    uci -q set wireless.default_radio${i}.key="$WIFI_PASS"
  fi
done

uci commit wireless
wifi reload
```

5. Нажмите **Request Build** и скачайте образ с пометкой **sysupgrade**.
6. Прошейте роутер через LuCI (`System` -> `Backup / Flash Firmware`), предварительно сняв галочку `Keep settings`.

## 2. Схема подключения и базовая настройка сети

Вы можете подключить ваш VPN-роутер к основному роутеру двумя способами: классическим кабелем или "по воздуху" (режим WISP). В любом случае, сначала необходимо устранить конфликт IP-адресов.

**Смена IP-адреса (решение конфликта подсетей):**
Большинство домашних роутеров используют базовый адрес `192.168.1.1`. Свежепрошитый OpenWrt тоже имеет адрес `192.168.1.1`. Если их просто соединить, возникнет конфликт IP-адресов. Нам нужно перенести наш VPN-роутер в другую подсеть (например, `192.168.10.1`).

1. **Не подключая** VPN-роутер к основному роутеру, подключитесь к нему напрямую (по WiFi `ShutAllRKN` или кабелем от компьютера в порт LAN).
2. Зайдите в браузере в веб-интерфейс `192.168.1.1` (пароля по умолчанию нет).
3. Перейдите в **Network** -> **Interfaces**.
4. В строке интерфейса **LAN** нажмите кнопку **Edit**.
5. В поле **IPv4 address** измените `192.168.1.1` на `192.168.10.1`.
6. Нажмите **Save**. Теперь внимание: если вы просто нажмете кнопку *Save & Apply* внизу страницы, включится таймер безопасности (90 секунд). Так как ваш IP-адрес изменится, браузер потеряет связь с роутером, вы не сможете нажать кнопку подтверждения, и роутер **откатит** настройки обратно на `192.168.1.1`.

> **Хитрость со "слепым" сохранением:** Чтобы избежать отката, нажмите на маленькую стрелочку рядом с кнопкой *Save & Apply* и выберите пункт **Apply unchecked** (Применить без проверки). Роутер применит новый IP-адрес навсегда. Страница в браузере "зависнет" на вечной загрузке (так как браузер ищет старый адрес). Просто подождите 10-15 секунд, переподключитесь к сети и вбейте в адресную строку новый адрес `192.168.10.1`.

### 2.1 Смена названия WiFi-сети и пароля

Если вы хотите изменить имя сети (SSID) и пароль, которые мы задали на этапе сборки прошивки (рекомендуется сделать это **до** настройки WISP-подключения, чтобы вас не выкинуло из сети):

1. Перейдите в **Network** -> **Wireless**.
2. В списке найдите вашу текущую сеть, которая раздает WiFi (её режим работы обозначен как **Mode: Master**), и нажмите **Edit**.
3. В разделе **Interface Configuration** -> **General Setup** измените поле **ESSID** на желаемое имя сети.
4. Перейдите на соседнюю вкладку **Wireless Security** и в поле **Key** впишите новый пароль.
5. Нажмите **Save**, а затем **Save & Apply**. (После этого вам нужно будет переподключиться к новой сети с вашего устройства).

### 2.2 Подключение кабелем (Двойной NAT)

Это самый надежный способ.
1. Возьмите патч-корд (сетевой кабель).
2. Один конец вставьте в свободный **LAN**-порт основного роутера.
3. Другой конец вставьте в **WAN**-порт VPN-роутера. Интернет появится автоматически.

### 2.3 Беспроводное подключение (Режим WISP)

Если протянуть кабель невозможно, роутер может брать интернет от основного роутера по WiFi, прогонять его через VPN и раздавать дальше через свою точку доступа.

1. В веб-интерфейсе `192.168.10.1` перейдите в **Network** -> **Wireless**.
2. Нажмите кнопку **Scan** (Поиск) возле того радиомодуля, которым хотите принимать интернет (желательно использовать 5GHz для максимальной скорости).
3. Найдите в списке вашу основную домашнюю WiFi-сеть и нажмите **Join Network** (Подключиться).
4. Введите пароль от вашей основной сети в поле **WPA passphrase**.
5. **Критически важно:** Убедитесь, что в поле **Network** (или "Имя новой сети") выбрана/написана сеть `wwan`. Если перед вами выпадающий список с галочками — снимите галочки с `lan` и `wan`, оставив **только `wwan`**.
6. Нажмите **Submit**, затем **Save & Apply**. Интернет появится.

> **Совет для путешественников:** Если вы будете часто переподключать роутер к разным WiFi-сетям (в отелях, гостях), со временем у вас накопится много "мусорных" интерфейсов (wwan1, wwan2...). Чтобы этого избежать, при подключении к новой сети ставьте галочку **Replace wireless configuration** (Заменить настройки) и выбирайте вашу старую клиентскую сеть, чтобы просто перезаписать её пароль, а не создавать новую сущность. Либо периодически удаляйте неактуальные сети кнопкой *Remove* в разделе Wireless.

## 3. Установка PassWall2 и Xray

Начиная с версии OpenWrt 25.12 используется пакетный менеджер `apk`. Пакет PassWall2 отсутствует в официальных репозиториях, поэтому его необходимо устанавливать из стороннего источника.

Подключитесь к роутеру по SSH (`ssh root@192.168.10.1`) и выполните следующие команды:

> Примечание: В примере ниже используется репозиторий для архитектуры `aarch64_cortex-a53`. Если ваш роутер использует другую архитектуру (узнать можно командой `uname -m`), замените архитектуру в ссылках.

```bash
# 1. Загрузка ключа репозитория
wget -O /etc/apk/keys/passwall.pem https://master.dl.sourceforge.net/project/openwrt-passwall-build/apk.pub

# 2. Добавление репозиториев PassWall2
echo "https://master.dl.sourceforge.net/project/openwrt-passwall-build/releases/packages-25.12/aarch64_cortex-a53/passwall_packages/packages.adb" >> /etc/apk/repositories.d/passwall.list
echo "https://master.dl.sourceforge.net/project/openwrt-passwall-build/releases/packages-25.12/aarch64_cortex-a53/passwall2/packages.adb" >> /etc/apk/repositories.d/passwall.list

# 3. Обновление списков пакетов
apk update

# 4. Установка PassWall2 и необходимых зависимостей (включая ядро Xray)
apk add luci-app-passwall2 xray-core v2ray-geoip v2ray-geosite geoview chinadns-ng tcping

# 5. Перезапуск веб-сервера интерфейса
/etc/init.d/uhttpd restart
```

## 4. Скрипт-парсер для нестандартных подписок

Некоторые провайдеры (например, приложения v2RayTun / Happ) защищают подписку специальными заголовками и отдают список серверов в формате JSON-массива с полными Xray-конфигами, а не стандартными Base64-ссылками. PassWall2 не умеет обрабатывать такие форматы "из коробки".

Для решения этой задачи создается локальный bash-скрипт с внедренным Lua-кодом, который скачивает JSON с нужными заголовками, преобразует его в формат VLESS-ссылок и кодирует в Base64.

1. В терминале SSH выполните команду для создания скрипта (заменив звездочки на вашу ссылку):

```bash
cat > /usr/bin/govpn-sub.sh << 'EOF'
#!/bin/sh
# Конвертер подписок GoVPN для PassWall2

# ВАША ССЫЛКА НА ПОДПИСКУ (замените на свою):
SUB_URL="https://auth.easy-api.live/****************"

# Загрузка JSON с использованием авторизационных заголовков
wget -qO /tmp/govpn.json --header="User-Agent: happ" --header="X-HWID: 1234567890" "$SUB_URL"

# Парсинг JSON и генерация VLESS ссылок
lua -e '
local jsonc = require("luci.jsonc")
local f = io.open("/tmp/govpn.json","r")
if not f then print("No JSON file"); os.exit(1) end
local t = f:read("*all")
f:close()
local cfgs = jsonc.parse(t)
if not cfgs then print("ERROR parsing JSON"); os.exit(1) end
local out = {}
for _,c in ipairs(cfgs) do
  local name = c.remarks or "unknown"
  if c.outbounds then
    for _,ob in ipairs(c.outbounds) do
      if ob.protocol=="vless" and ob.settings and ob.settings.vnext then
        local v = ob.settings.vnext[1]
        if v and v.address ~= "0.0.0.0" then
          local uid = v.users and v.users[1] and v.users[1].id or ""
          local flow = v.users and v.users[1] and v.users[1].flow or ""
          local ss = ob.streamSettings or {}
          local p = {}
          if ss.network then p[#p+1]="type="..ss.network end
          if ss.security then p[#p+1]="security="..ss.security end
          if ss.realitySettings then
            local r=ss.realitySettings
            if r.serverName then p[#p+1]="sni="..r.serverName end
            if r.fingerprint then p[#p+1]="fp="..r.fingerprint end
            if r.publicKey then p[#p+1]="pbk="..r.publicKey end
            if r.shortId then p[#p+1]="sid="..r.shortId end
          end
          if ss.tlsSettings then
            local ts=ss.tlsSettings
            if ts.serverName then p[#p+1]="sni="..ts.serverName end
            if ts.fingerprint then p[#p+1]="fp="..ts.fingerprint end
          end
          if flow~="" then p[#p+1]="flow="..flow end
          if ss.wsSettings then
            local ws=ss.wsSettings
            if ws.path then p[#p+1]="path="..ws.path end
            if ws.headers and ws.headers.Host then p[#p+1]="host="..ws.headers.Host end
          end
          out[#out+1]=string.format("vless://%s@%s:%d?%s#%s",uid,v.address,v.port,table.concat(p,"&"),name)
        end
      end
    end
  end
end
local result=table.concat(out,"\n")
io.write(result)
' > /tmp/govpn-links.txt

# Кодирование результата в Base64 для PassWall2
base64 /tmp/govpn-links.txt > /www/govpn-sub.txt
echo "Done! $(wc -l < /tmp/govpn-links.txt) servers found"
EOF

chmod +x /usr/bin/govpn-sub.sh
```

2. Выполните первичный запуск скрипта:
```bash
govpn-sub.sh
```

**Обновление списка серверов (в рамках одной подписки):**
Для подгрузки свежих серверов достаточно подключиться к роутеру по SSH, запустить команду `govpn-sub.sh` (или настроить автоматизацию, см. п.6), а затем в интерфейсе PassWall2 нажать кнопку `Manual subscription`.

**Смена ссылки (если подписка закончилась и вы купили новую):**
Скрипт пересоздавать не нужно, достаточно просто отредактировать ссылку внутри него:
1. Подключитесь к роутеру по SSH.
2. Откройте скрипт во встроенном текстовом редакторе:
   ```bash
   vi /usr/bin/govpn-sub.sh
   ```
3. Нажмите английскую клавишу `i` (переход в режим редактирования).
4. Найдите строку `SUB_URL="..."` и аккуратно замените старую ссылку на новую внутри кавычек.
5. Нажмите клавишу `Esc`, затем введите `:wq` и нажмите `Enter` (чтобы сохранить изменения и выйти).
6. Запустите скрипт командой `govpn-sub.sh`, после чего обновите подписку в PassWall2.

## 5. Настройка маршрутизации PassWall2

После того как список серверов сформирован локально, его нужно добавить в PassWall2.

1. В веб-интерфейсе перейдите в **Services** -> **PassWall2**.
2. Откройте вкладку **Node Subscribe** и создайте новую подписку.
3. В поле **Subscribe URL** укажите локальный адрес: `http://127.0.0.1/govpn-sub.txt`
4. Сохраните изменения (**Save & Apply**) и нажмите **Manual subscription**. Маршрутизатор загрузит все сконвертированные серверы.
5. На вкладке **Node List** найдите предпочтительный сервер (с наименьшим пингом) и нажмите кнопку **Use**.
6. На вкладке **Basic Settings**:
   - Включите **Main switch**.
   - Активируйте **Localhost Proxy** и **Client Proxy** (для маршрутизации трафика локальной сети через VPN).
   - Нажмите **Save & Apply**.
7. Если требуется направлять **весь трафик** через VPN без исключений, перейдите на вкладку **Access control** (или **Rule Manage**) и убедитесь, что действие по умолчанию для LAN настроено на **Proxy**, а не Direct.

> Важно: Интерфейс LuCI может отображать статус `Core NOT RUNNING` даже при корректно работающем ядре Xray. Это известная проблема отображения, которая не влияет на фактическую работу туннеля.

## 6. Обновление подписки с телефона (Termux)

Поскольку роутер может использоваться как портативное устройство, удобно обновлять серверы прямо с телефона в один клик без необходимости заходить в веб-интерфейс.

На устройстве Android можно использовать терминал **Termux**.

1. Откройте Termux и установите пакеты для работы SSH:
```bash
pkg update
pkg install openssh sshpass -y
```

2. Вставьте в терминал команду ниже (предварительно заменив пароль на свой), чтобы в один клик создать готовый скрипт и сделать его исполняемым. 
*(Примечание: Команда сама создаст нужный файл внутри защищенной памяти Termux, root-права на телефоне для этого не требуются).*

```bash
cat > update_vpn.sh << 'EOF'
#!/bin/bash

ROUTER_IP="192.168.10.1" # Убедитесь, что IP совпадает с вашим
ROUTER_PASS="СЮДА_ВПИШИТЕ_ВАШ_ПАРОЛЬ"

echo "Подключение к роутеру $ROUTER_IP..."
sshpass -p "$ROUTER_PASS" ssh -o StrictHostKeyChecking=no root@$ROUTER_IP "govpn-sub.sh"
echo "Подписка успешно обновлена на роутере!"
EOF

chmod +x update_vpn.sh
```

3. Теперь для обновления подписки с телефона достаточно зайти в Termux и запустить:
```bash
./update_vpn.sh
```

> Рекомендация: Также можно настроить автоматическое ежедневное обновление подписки в самом роутере. Для Того чтобы подписка автоматически загружалась каждый день в 4 утра, перейдите в **System** -> **Scheduled Tasks** и добавьте строку:
> `0 4 * * * /usr/bin/govpn-sub.sh`

## 7. Бонус: Аппаратный переключатель VPN (Только для Cudy TR3000)

Роутер Cudy TR3000 оснащен физическим ползунком на корпусе, который в заводской прошивке включает и выключает VPN. В OpenWrt мы можем привязать этот тумблер к управлению нашим `PassWall2`! 
Более того, мы сделаем так, чтобы **при переключении тумблера роутер сначала автоматически скачивал свежую подписку серверов**, а уже потом запускал туннель.

1. Подключитесь к роутеру по SSH.
2. Вставьте этот блок кода целиком (он создаст скрипт, реагирующий на физическую кнопку `BTN_0`):

```bash
cat > /etc/rc.button/BTN_0 << 'EOF'
#!/bin/sh

if [ "$ACTION" = "pressed" ]; then
    logger "VPN Switch: ON - Updating servers and starting VPN..."
    
    # Включаем "Злой режим" (Красный диод)
    echo none > /sys/class/leds/white:status/trigger
    echo none > /sys/class/leds/red:power/trigger
    echo 0 > /sys/class/leds/white:status/brightness
    echo 1 > /sys/class/leds/red:power/brightness

    # Качаем свежие узлы
    /usr/bin/govpn-sub.sh
    # Включаем PassWall2
    uci set passwall.@global[0].enabled='1'
    uci commit passwall
    /etc/init.d/passwall restart
elif [ "$ACTION" = "released" ]; then
    logger "VPN Switch: OFF - Stopping VPN..."
    
    # Включаем "Мирный режим" (Белый диод)
    echo none > /sys/class/leds/red:power/trigger
    echo none > /sys/class/leds/white:status/trigger
    echo 0 > /sys/class/leds/red:power/brightness
    echo 1 > /sys/class/leds/white:status/brightness

    # Выключаем PassWall2
    uci set passwall.@global[0].enabled='0'
    uci commit passwall
    /etc/init.d/passwall stop
fi

return 0
EOF

chmod +x /etc/rc.button/BTN_0
```

Теперь физический тумблер на роутере полностью управляет вашим интернетом! В положении ON он обновляет сервера и пускает трафик через VPN, в положении OFF — возвращает прямой интернет.

> **Примечание:** Если логика работы переключателя оказалась перевернутой (VPN включается в положении OFF), просто поменяйте местами слова `pressed` и `released` в скрипте командой `vi /etc/rc.button/BTN_0`.

## 8. Настройка файлового сервера (SMB и FTP)

Все необходимые пакеты для работы с USB-накопителями (`kmod-usb-storage`, драйверы ФС, `ksmbd-server`, `vsftpd`) были интегрированы на первом шаге. Настройка сводится к нескольким кликам в веб-интерфейсе.

1. Подключите USB-накопитель к роутеру.
2. Перейдите в **System** -> **Mount Points**. Убедитесь, что диск был обнаружен и смонтирован (например, по пути `/mnt/sda1`). Активируйте чекбокс `Enabled` и сохраните настройки.
3. **Настройка SMB-сервера:**
   - Перейдите в **Services** -> **Network Shares** (Настройки ksmbd).
   - Добавьте новую директорию. Укажите произвольное имя (например, `USB`) и путь `/mnt/sda1`.
   - Для публичного доступа без пароля установите флажки `Browseable` и `Allow guests`.
   - Нажмите **Save & Apply**.
4. **Настройка FTP-сервера:**
   - Перейдите в **Services** -> **FTP Server**.
   - Укажите в качестве корневой директории `/mnt/sda1`.
   - Включите опцию анонимного доступа, если не планируете использовать строгую авторизацию.

Роутер готов к работе в качестве защищенного шлюза и домашнего файлового хранилища.

## 9. Автообновление подписки при загрузке роутера

Чтобы роутер самостоятельно скачивал самые свежие сервера каждый раз, когда вы втыкаете его в розетку (или после перезагрузки), мы добавляем вызов скрипта-парсера в автозагрузку системы.

1. Подключитесь по SSH.
2. Откройте файл автозагрузки командой: `vi /etc/rc.local`
3. Добавьте строку `/usr/bin/govpn-sub.sh` перед строчкой `exit 0`. 

Либо выполните команду, которая сделает это автоматически:
```bash
sed -i '/exit 0/i /usr/bin/govpn-sub.sh' /etc/rc.local
```

Всё! Теперь роутер полностью автономен и не требует ручного вмешательства для обновления базы.

## 10. Удаление скриптов и откат изменений

Если вы решили сменить VPN-провайдера, перейти на собственный сервер или просто хотите вернуть всё "как было", вот команды для полной очистки роутера от наших скриптов.

### Отключение автообновления при загрузке
Если вы хотите, чтобы скрипт перестал запускаться при включении роутера в розетку, просто удалите его из автозагрузки одной командой:
```bash
sed -i '/govpn-sub.sh/d' /etc/rc.local
```

### Отключение "магии" аппаратного тумблера
Чтобы тумблер перестал управлять вашим интернетом и цветом светодиодов (вернулся к заводскому неактивному поведению), удалите привязанный к нему скрипт:
```bash
rm /etc/rc.button/BTN_0
```

### Полное удаление скрипта подписок (при смене провайдера)
Если скрипт-парсер вам больше не нужен:
1. Удалите текстовый файл с вашей ссылкой на подписку:
```bash
rm /etc/govpn_url.txt
```
2. Удалите сам исполняемый скрипт-парсер:
```bash
rm /usr/bin/govpn-sub.sh
```
3. Зайдите в веб-интерфейс роутера (PassWall2 -> Node Subscribe) и удалите подписку оттуда.

> **Примечание:** Если вы хотите полностью сбросить роутер до состояния "только что прошили", просто перейдите в веб-интерфейсе в меню **System -> Backup / Flash Firmware** и нажмите кнопку **Perform reset** (Сброс к заводским настройкам). Это удалит вообще все настройки, оставив только чистый OpenWrt.
